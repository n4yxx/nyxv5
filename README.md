Possible Issues
Half of the time its usually the scripting utility at fault, please make sure the utility meets certain quality standards such as.

Supporting file functions & the debug library.
Not implementing lua generated / half baked versions of such functions resulting in unintended behavior.
Maintaining the same behavior across all usages of said functions.
User Issues
If its not the supposed utility at fault, please try some troubleshooting steps.

Deleting the newvape folder (WITH THE GAME CLOSED).
Making sure you have connection to the main loadstring.
Ensuring no external script is conflicting with vape.
